# My_link_hy 🔗

개인 프로필과 주요 소셜 링크를 한곳에서 간편하게 공유할 수 있는 모바일 친화적 링크트리 웹 애플리케이션입니다.

## ✨ 주요 기능
- **반응형 디자인**: 모바일 및 데스크톱 환경에 최적화된 심플하고 직관적인 UI
- **다크 모드 지원**: 사용자 시스템 테마에 맞춘 자동 라이트/다크 모드 제공
- **빠른 로딩 & 성능**: Next.js App Router와 Tailwind CSS 기반의 가볍고 빠른 렌더링

## 🛠 기술 스택
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Package Manager**: npm

## 🚀 로컬 실행 방법

```bash
# 저장소 클론
git clone https://github.com/suzyoh02/My_link_hy.git

# 프로젝트 폴더로 이동
cd My_link_hy

# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 https://suzyoh02.github.io/mylink_hy/ 으로 접속하면 확인할 수 있습니다.
